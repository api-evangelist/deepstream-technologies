# DeepStream Technologies

> DeepStream is an AI-enhanced eSourcing and source-to-contract platform for mid-market procurement teams, headquartered in London, UK. It digitalizes buyer-to-supplier sourcing with best-of-breed eRFx, supplier discovery, pre-qualification, eAuctions, contract management, and AI RFP generation and analytics. This is a company profile in the API Evangelist network; DeepStream does not currently publish a public developer API, OpenAPI specification, or developer documentation.
